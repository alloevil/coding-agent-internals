# Codex

> OpenAI 出品，云端自主编程代理

| 项 | 值 |
|----|---|
| 出品方 | OpenAI |

## 设计哲学

"你当产品经理，它当整个开发团队。"

提交任务 → 云端沙箱独立执行 → 自动创建 GitHub PR。多个任务可并行。

## 核心能力

### 云端沙箱并行
每个任务在独立云端容器中执行：读代码、装依赖、改文件、跑测试、生成 diff。
- 多任务同时跑，去做别的事，回来收 PR
- Goals 模式：自动规划执行路径

### 自动 PR
跑测试确认没问题后自动创建 GitHub PR。

### 三入口
CLI + Desktop App + Web/Cloud。

## 工具实现

| 维度 | 实现方式 | 层级 |
|------|---------|------|
| 搜索 | 内置 | — |
| 编辑 | 纯文本替换 | Level 1 |
| 执行环境 | 云端沙箱 | Level 2（安全） |
| Git | 自动分支 + PR | 最强 |
| 安全 | 云端沙箱隔离 | Level 2 |

## 优势

- 并行委派最强（云端沙箱同时跑多个任务）
- 1M 上下文（GPT-5.5）
- 自动 PR 工作流最成熟
- 云端沙箱天然安全隔离

## 劣势

- 仅支持 GPT 模型
- 工具层简单
- 不适合实时交互（给完任务就离开）
- 成本不透明（GPT-5.5 输出 $30/M token，长会话烧得快）
- 国内需翻墙
- 云端沙箱依赖 OpenAI 服务器
