| 项 | 值 |
|----|---|
| 出品方 | Anysphere |

## 设计哲学

"让编辑器变聪明，而不是取代编辑器。"

## 核心能力

### Tab 补全（业界最强 2026）
不只补全当前行，预测接下来 3-5 行逻辑走向。
- 写完函数签名 → 预测整个函数体
- 写完 if 判断 → 补完 else 分支
- "它知道我想干什么"的感觉

### Composer 2
跨多文件同时编辑，Agent 模式可自主规划任务。

### Agent 模式
自主执行任务，适合中等复杂度（10-20 个文件以内）。

### MCP 协议
支持 Model Context Protocol。

## 优势

- 日常编码体验碾压（Tab 补全）
- IDE 集成零学习成本（VS Code 用户直接上手）
- 多模型支持
- 覆盖最常见编码场景

## 劣势

- 不适合超过 20 个文件的自主任务（上下文理解偏差）
- 无终端 Agent 能力（不是 Claude Code 那种"扔任务走人"）
- 高级功能依赖 Cursor 服务器，国内连接不稳定
- 闭源
