# Cline

> 开源的 AI Coding VS Code 插件

## 基本信息

| 项 | 值 |
|----|---|
| 出品方 | 开源社区 |
| 形态 | VS Code 插件 |
| 模型 | 多模型（BYO Key） |
| 开源 | ✅ |
| 价格 | 免费（BYO API Key） |

## 核心能力

- **自主执行**（Agent 模式）
- **MCP 协议**支持
- 会话历史管理（分页、收藏）
- 系统托盘图标

## Fork 项目

| 项目 | 特点 |
|------|------|
| **Kilo Code** | Cline fork，免费，本地模型支持 |
| **Roo Code** | Cline fork，自定义 persona |

## 工具实现

| 维度 | 实现方式 | 层级 |
|------|---------|------|
| 搜索 | VS Code 搜索 | Level 2 |
| 编辑 | VS Code 编辑 API | Level 2 |

## 优势

- 完全开源免费
- MCP 支持
- 多个活跃 fork 可选

## 劣势

- 无 Tab 补全
- 依赖 VS Code 环境
- 功能不如 Cursor 全面
