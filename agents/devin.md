# Devin

> 24/7 自主工程师

## 基本信息

| 项 | 值 |
|----|---|
| 出品方 | Cognition |
| 形态 | 独立平台（浏览器 + 终端 + 编辑器一体） |
| 开源 | ❌ |
| 价格 | Free / Pro $20/月 / Max $200/月 / Teams（按量计费，最低 $80/月）/ Enterprise 定制——[Cognition 2026-04-14 公告](https://cognition.com/blog/new-self-serve-plans-for-devin) |

## 设计哲学

"你雇了一个工程师，不是用了一个工具。"

## 核心能力

- **全栈自主**：浏览器 + 终端 + 编辑器一体化
- **云端隔离环境**：每个任务独立容器
- **自动创建 PR**
- **自然语言交互**：用人类语言描述任务

## 工具实现

| 维度 | 实现方式 | 层级 |
|------|---------|------|
| 执行环境 | 云端一体 | Level 2（安全） |
| 浏览器 | ✅ 内置 | — |
| 终端 | ✅ 内置 | — |
| 编辑器 | ✅ 内置 | — |
| 安全 | 云端沙箱隔离 | Level 2 |

## 优势

- 最"像人"的 Agent（浏览器 + 终端 + 编辑器）
- 云端隔离天然安全
- 可处理全栈任务

## 劣势

- 成本不透明：2026-04 起改为 Free / Pro $20 / Max $200 / Teams（最低 $80/月，按量计费）
- 闭源不可审计
- 依赖 Cognition 云端服务
- 不适合实时交互（异步执行）
- 国内访问受限
