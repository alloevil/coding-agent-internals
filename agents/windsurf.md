# Windsurf

> Codeium 出品的 AI IDE

## 基本信息

| 项 | 值 |
|----|---|
| 出品方 | Codeium |
| 形态 | VS Code Fork IDE |
| 模型 | 多模型 |
| 开源 | ❌ |
| 价格 | $15/月 |

## 核心能力

- **Cascade**：智能补全 + 多文件推理
- Agent 模式
- MCP 支持

## 工具实现

| 维度 | 实现方式 | 层级 |
|------|---------|------|
| 搜索 | IDE 原生（VS Code 搜索引擎） | Level 2 |
| 编辑 | VS Code 编辑 API | Level 2 |
| LSP | ✅ IDE 原生 | Level 2 |
| DAP | ✅ IDE 调试 | Level 2 |

## 优势

- Cascade 智能补全
- 价格比 Cursor 低
- VS Code 生态兼容

## 劣势

- 生态和用户基数不如 Cursor
- 闭源
- 国内连接不稳定
